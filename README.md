# AlphaA1-AI

A C++ Tic-Tac-Toe project featuring **AlphaA1**, an unbeatable AI that uses Minimax with Alpha-Beta pruning.

## Files
- `AlphaA1.h` — header-only AI library.
- `main.cpp` — terminal game application that uses `AlphaA1`.

## Build
```bash
g++ -std=c++17 -O2 -Wall -Wextra -pedantic main.cpp -o alphaa1
```

## Run
```bash
./alphaa1
```
